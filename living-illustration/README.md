# 會動的插畫

把一張水彩人物插畫（`source.jpg`）做成 960×1920（H.264 Level 4.1，手機相容）、可以無縫循環的動態插畫，有配樂。

- `living_loop_12s.mp4`：12 秒無縫循環版（適合設成重複播放、桌布）
- `living_illustration.mp4`：24 秒版（循環兩次）

## 動了哪些地方
| 部位 | 動作 | 週期 |
|---|---|---|
| 頭 | 輕輕左右歪頭 | 6 秒＋3 秒疊加 |
| 髮尾 | 慢半拍跟著飄 | 3 秒 |
| 比 YA 的手 | 左右搖，前臂跟著微動 | 2 秒 |
| 上半身 | 呼吸起伏 | 4 秒 |
| 全身 | 以腳為支點輕微搖擺（鞋子固定不動） | 6 秒 |
| 長裙 | 波浪狀擺動，越往裙襬越大 | 3 秒 |
| 眼睛 | 眨眼 4 次（含一次連眨兩下） | — |
| 前景 | 飄落的葉子、上升的光點 | 12 秒 |

## 做法
先用 `mask.py` 把人物和背景分開：從畫面邊緣把「像背景的顏色」一路填進來，填不到的就是人物。顏色太接近白紙的長裙下半部和球鞋，則用描好的輪廓補進遮罩。被人物擋住的背景用金字塔補色法補起來，做成一張**完全靜止的背景**。

人物層則對原圖套用「局部、平滑的位移場」（反向映射＋雙線性取樣），所以不會露出破洞，水彩筆觸和紙紋都保留原樣。眨眼是用眼睛周圍取樣的膚色蓋上，再畫一條閉眼線，並跟著頭部一起變形。所有動作的週期都整除 12 秒，所以首尾無縫；音樂也寫在環狀緩衝區裡，尾音會繞回開頭。

```bash
./build.sh
python3 animate.py --stills 0,2.3,4.5   # 只輸出預覽圖
```
