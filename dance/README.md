# 跳舞的女孩 — 手繪風舞蹈動畫

25.5 秒、1280×720、24fps，配一首 120 BPM 的原創舞曲，所有舞步都卡在節拍上。

| 時間 | 舞步 |
|---|---|
| 0–4s | 左右搖擺、膝蓋律動，第 2、4 拍彈指 |
| 4–8s | 左右踏併步，雙手跟著甩 |
| 8–12s | 舉手過頭做波浪，接迪斯可指天 |
| 12–14s | 踮腳轉一圈，裙擺張開、馬尾甩出去 |
| 14–18s | 開合跳 ×3、抱膝跳 ×1 |
| 18–22s | 交叉側步，高舉過頭拍手 |
| 22–25s | 單手指天定格、眨眼，彩紙灑下 |

## 角色怎麼動的
- **骨架**：脊椎、頭、肩、肘、髖、膝、腳踝。手臂用正向運動學（FK）擺角度，腿用兩段式 IK，腳可以穩穩踩在指定位置不滑步
- **編舞**：在節拍格上放關鍵姿勢，中間用緩入緩出補間（pose-to-pose）。腳移動距離夠遠時會自動抬腳
- **跟隨動作**：馬尾用 Verlet 彈簧鏈模擬，裙擺張開幅度和擺動用彈簧追隨旋轉和髖部速度
- **圖層**：手舉過頭時，手臂自動改畫在頭的後面

## 產生影片
```bash
./build.sh                               # 輸出 out/dance.mp4
node render.js --stills 1.5,10,12.6,14.3 # 只輸出預覽圖
```
