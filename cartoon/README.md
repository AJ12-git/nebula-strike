# 起司大作戰（Cheese Heist）— 手繪風貓捉老鼠短片

30 秒、1280×720、24fps 的手繪風卡通，角色是原創的：橘色虎斑貓和圍紅圍巾的小灰鼠。

| 時間 | 劇情 |
|---|---|
| 0–3.5s | 小老鼠從牆洞探頭，左右張望，聞到起司味 |
| 3.5–9s | 躡手躡腳經過睡著的貓，嚇得原地僵住、冒冷汗 |
| 9–13s | 爬上桌腳，舉起起司得意洋洋 |
| 13–14.5s | 貓驚醒飛撲，老鼠跳下桌，貓撞碎盤子 |
| 14.5–21s | 全屋追逐：急煞、撞到盆栽、在地毯上滑倒翻跟斗 |
| 21–24s | 老鼠鑽回洞，貓一頭撞牆 BONK！畫框掉下來套在頭上 |
| 24–28s | 老鼠悠哉吃起司偷笑、對鏡頭眨眼揮手，圓形收尾 |
| 28–30s | The End |

## 手繪感怎麼做的
- [Rough.js](https://roughjs.com/) 畫出不完美的手繪線條
- 每 1/12 秒換一次亂數種子，線條會「抖」，就像傳統逐格重描的動畫
- 填色故意和線條錯開一點，加上鉛筆排線陰影和紙張紋理

## 產生影片
```bash
./build.sh                                  # 輸出 out/cheese_heist.mp4
node render.js --stills 6.3,13.8,21.3       # 只輸出預覽圖
```
- `index.html`：場景、角色、劇情時間軸（所有動作都是時間 `t` 的函數）
- `render.js`：無頭 Chromium 逐格渲染，丟給 ffmpeg 編碼
- `audio.py`：用 numpy 合成配樂與音效（撥弦、木琴、滑音哨、BONK…）
